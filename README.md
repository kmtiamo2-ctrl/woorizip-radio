# 우리집 무전기 — 설치 안내 (쉬운 버전)

가족 5명(엄마·아빠·첫째·둘째·셋째)이 **폰 5대 + 데스크톱 + 노트북**으로 함께 쓰는 가족 무전기예요.

**이렇게 동작해요**
- **집에서**: 누가 말하면 가족 모두의 폰·PC 스피커에서 바로 들려요. (진짜 무전기처럼)
- **밖에 있는 엄마·아빠**: 폰 데이터로 바로 소리가 울려요.
- **밖에 있는 아이들**: 소리 없이 **진동 + 알림**만 와요. 알림의 **[듣기]**를 누르면 그때 들려요. (밖에서 창피하지 않게)
- **데이터가 안 될 때**(지하철 등): 서버가 보관했다가 연결되면 전달해요.
- 한 사람에게만 말하기(1:1)도 돼요. 그 사람의 폰과 PC에서만 들려요.
- **말하기 어려울 때는 글로** 보낼 수 있어요. "응", "알았어", "지금 가" 같은 빠른 답장 버튼도 있고, 폰은 알림에서 바로 답장돼요. 집에 있는 폰은 받은 글을 소리로 읽어 줘요.

---

## 준비물 체크

- [ ] 시놀로지 NAS에 **Container Manager**가 설치되어 있음
- [ ] NAS에 **Tailscale**이 설치되어 있음 (밖에서 쓰려면)
- [ ] Windows PC, 안드로이드 폰

---

## 1단계. NAS에 서버 올리기 (10분, 한 번만)

1. **NAS 주소 고정하기** — 공유기 관리 화면에서 NAS에 고정 IP(DHCP 예약)를 걸어 주세요. 예: `192.168.0.10`
   (이미 고정돼 있으면 건너뛰세요. NAS 제어판 → 네트워크 → 네트워크 인터페이스에서 현재 주소를 볼 수 있어요.)
2. **File Station**을 열고 `docker` 공유 폴더 안에 `woorizip-radio` 라는 폴더를 만드세요.
3. 이 묶음의 `server` 폴더 안에 있는 **파일 3개**(`server.py`, `Dockerfile`, `docker-compose.yml`)를 그 폴더에 올리세요.
4. 올린 `docker-compose.yml`을 File Station에서 **우클릭 → 텍스트 편집기로 열기** 하고,
   `FAMILY_KEY: "여기에-가족-암호-입력"` 부분을 **가족만 아는 암호**로 바꾸고 저장하세요. (예: `"우리집2026"`)
   엄마·아빠 외에 밖에서도 소리로 받을 사람이 있으면 `PARENTS`에 이름을 추가하세요.
5. **Container Manager → 프로젝트 → 생성**
   - 프로젝트 이름: `woorizip-radio`
   - 경로: `/docker/woorizip-radio` 선택
   - 원본: **기존 docker-compose.yml 사용**
   - 다음 → 다음 → 완료. 1~2분 뒤 자동으로 실행돼요.
6. **확인**: PC 브라우저에서 `http://192.168.0.10:8765` 를 열어 `woorizip-radio ok` 가 보이면 성공!
7. NAS **Tailscale 주소 적어 두기**: NAS의 Tailscale 패키지를 열면 `100.xx.xx.xx` 같은 주소가 보여요. 이게 "밖 주소"예요.

> 공유기 포트포워딩은 **필요 없어요.** NAS 방화벽을 쓰고 있다면 TCP 8765를 허용하세요.

## 2단계. 내려받기

GitHub 저장소의 **Releases** 페이지에서 가장 위에 있는 최신 빌드를 열면 파일 2개가 있어요.

- `WoorizipRadio-PC.exe` → PC용
- `WoorizipRadio-Phone.apk` → 폰용

---

## 3단계. PC 설치 (데스크톱·노트북 각각)

1. `WoorizipRadio-PC.exe`를 **바탕화면 같은 곳에 두고** 더블클릭하세요. 설치 과정 없이 바로 실행돼요.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요. (가족용 프로그램이라 서명이 없어서 그래요)
2. 처음 실행하면 **설정 창**이 떠요.
   - 집 주소: `192.168.0.10` (1단계에서 고정한 NAS 주소)
   - 밖 주소: NAS의 Tailscale 주소 `100.xx.xx.xx` (노트북을 밖에서도 쓸 때. 데스크톱은 비워도 돼요)
   - 이 PC를 주로 쓰는 가족: `아빠` 처럼 이름 하나
   - 가족 암호: 1단계의 `FAMILY_KEY`와 똑같이
   - 단축키: 비워 두면 없음. 게임 중에도 말하고 싶으면 `f9`
   - Windows 시작 시 자동 실행: 켜 둔 채로
3. **저장하고 연결**을 누르면 끝. 오른쪽 아래 시계 옆에 **무전기 아이콘**이 생겨요.
   - 창을 닫아도 아이콘으로 남아 계속 듣고 있어요.
   - 가족이 말하면 **알림 풍선**이 뜨고 스피커(헤드셋을 꽂았으면 헤드셋)로 들려요.
   - 아이콘을 누르면 창이 열리고, 상대를 고른 뒤 큰 버튼을 누른 채 말하면 돼요.
   - 완전히 끄려면 아이콘 우클릭 → **완전히 종료**
4. 실행 파일을 삭제하면 제거돼요. 자동 실행 등록은 설정 창에서 끄고 삭제하세요.

---

## 4단계. 폰 설치 (가족 폰 5대 각각)

**(밖에서도 쓰려면) Tailscale 먼저**
1. 플레이스토어에서 **Tailscale**을 설치하고, NAS에서 쓴 것과 **같은 계정**으로 로그인하세요.
2. 연결(Connected)로 켜 두세요. 설정에서 **항상 켜진 VPN**으로 해 두면 꺼지지 않아요.
   (집에서만 쓸 거면 이 단계는 건너뛰어도 돼요.)

**우리집 무전기 앱**
1. `WoorizipRadio-Phone.apk`를 폰으로 보내서(카톡 나에게 보내기, NAS 등) 눌러 설치하세요.
   "출처를 알 수 없는 앱" 허용을 물으면 허용하세요.
2. 앱을 열면 설정이 보여요.
   - 집 주소: `192.168.0.10`
   - 밖 주소: NAS Tailscale 주소 `100.xx.xx.xx`
   - 내 이름: `첫째` 처럼
   - 가족 암호: 똑같이
3. **저장하고 연결** → 마이크·알림 권한 **허용**
4. **배터리 최적화 제외** 버튼을 누르고 허용하세요.
5. **삼성 폰은 한 가지 더**: 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 "우리집 무전기" 추가.
   안 하면 몇 시간 뒤 수신이 끊길 수 있어요.
6. 상단에 "우리집 무전기 · 수신 대기 중" 알림이 떠 있으면 준비 끝!

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 모두에게 말하기 | **전체** 선택 → 큰 버튼 누른 채 말하기 → 손 떼면 끝 |
| 한 사람에게 말하기 | 그 사람 이름 선택 → 큰 버튼 |
| 폰 화면 꺼진 채로 말하기 | **볼륨 버튼 길게** 누른 채 말하기 (마지막에 고른 상대에게) |
| 잠금 화면에서 | 알림의 **[말하기 시작] / [말하기 끝]** 버튼 |
| 밖에서 받은 말 듣기 (아이) | 알림의 **[듣기]**, 또는 앱의 **받은 메시지**에서 |
| PC에서 말하기 | 아이콘 클릭 → 창에서 큰 버튼 (단축키를 넣었으면 그 키) |
| 말할 수 없을 때 (회의·수업 중) | **글로 보내기**: 빠른 답장 버튼 또는 직접 입력 → 보내기 |
| 폰 알림에서 바로 답장 | 알림의 **[답장]** → 글 선택 또는 입력 |
| 잠깐 조용히 | **방해금지** 켜기 |

- 말하기가 시작되면 **"삐" + 짧은 진동**, 다른 사람이 말하는 중이면 **낮은 음 + 두 번 진동**이에요.
- 가족 이름 아래 **집 / 밖** 표시로 지금 어디 있는지 알 수 있어요.
- 한 번에 한 사람만 말할 수 있고, 한 번에 최대 1분이에요.

## 알아 두면 좋은 것

- **화면 꺼진 상태 볼륨키 말하기는 기종마다 달라요.** 안 되면 앱 설정에서 "두 번 눌러 켜기/끄기"로 바꿔 보고, 그래도 안 되면 잠금 화면 알림 버튼을 쓰세요.
- **폰을 재부팅하면 앱을 한 번 열어야** 다시 수신돼요. (안드로이드 규칙) 재부팅 후 알림이 떠요.
- 밖에서는 Tailscale이 켜져 있어야 연결돼요. 아이 폰에서 Tailscale을 꺼 버리면 집에서만 돼요.
- 배터리는 메신저 앱 하나 더 켜 둔 정도예요. 위치 추적은 전혀 안 해요.
- PC 프로그램은 트레이에 조용히 있을 때 메모리를 거의 쓰지 않도록 만들었어요 (받은 음성은 파일로만 보관).
- 음성은 NAS 메모리에만 잠깐(최대 24시간) 보관되고 파일로 저장되지 않아요. 폰·PC에는 최근 30개만 남아요.

## 처음 해 볼 테스트 (폰 1대 + PC 1대)

- [ ] 둘 다 "● 지금 집" 표시
- [ ] PC에서 말하면 폰에서 들림 / 폰에서 말하면 PC에서 들림
- [ ] 폰 화면 끄고 PC에서 말해도 폰에서 들림
- [ ] 폰 화면 끈 채 볼륨 버튼 길게 눌러 말하면 PC에서 들림
- [ ] 폰 Wi-Fi를 끄고(데이터만) 앱이 "지금 밖"으로 바뀌는지 → PC에서 말하면 부모는 소리, 아이는 진동+알림
- [ ] 폰 앱을 껐다가 다시 켜면 그동안 온 말이 "받은 메시지"에 있는지

안 되는 항목이 있으면 **어느 기기에서 어떤 항목**이 안 되는지 알려 주세요.
