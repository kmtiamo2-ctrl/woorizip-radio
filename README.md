# 우리집 무전기 — 1단계 설치 안내

집 Wi-Fi 안에서만 동작하는 가족 무전기입니다. 가족 5명(엄마·아빠·첫째·둘째·셋째)이 스마트폰 5대 + 데스크톱 + 노트북으로 함께 씁니다.
한 사람이 폰과 PC를 동시에 켜 두어도 되고, 그 사람에게 말하면 양쪽 모두에서 들립니다.
- **전체 방송**: 한 명이 말하면 접속한 가족 모두에게 들림
- **1:1 무전**: 가족 한 명을 골라서 말하기
- **화면 꺼짐 수신**: 수신 대기를 켜 두면 화면이 꺼져도 들림
- **화면 꺼짐 송신**: 볼륨 버튼을 길게 누르는 동안 말하기 (또는 두 번 눌러 켜고 끄기)
- 한 번에 한 사람만 말할 수 있음 (무전기 방식), 한 번에 최대 1분

```
woorizip-radio/
├─ server/     NAS에 올리는 중계 서버 (Docker)
├─ android/    가족 폰에 설치할 앱 (Android Studio로 빌드)
└─ pc/         데스크톱·노트북용 프로그램 (설치.bat 실행)
```

---

## 1. NAS에 서버 설치 (시놀로지 Container Manager)

1. **NAS 주소 고정**: 공유기 관리 화면에서 NAS에 고정 IP(DHCP 예약)를 걸어 주세요. 예: `192.168.0.10`
2. **File Station**에서 `docker` 공유 폴더 안에 `woorizip-radio` 폴더를 만들고, `server` 폴더 안의 파일 3개(`server.py`, `Dockerfile`, `docker-compose.yml`)를 올립니다.
3. 올린 `docker-compose.yml`을 열어 **`FAMILY_KEY`를 가족만 아는 암호로 바꿉니다.**
   가족 이름을 바꾸고 싶으면 `MEMBERS`도 수정하세요 (쉼표로 구분).
4. **Container Manager → 프로젝트 → 생성**
   - 경로: `/docker/woorizip-radio`
   - 원본: "기존 docker-compose.yml 사용"
   - 다음 → 완료하면 이미지 빌드 후 자동 실행됩니다.
5. **확인**: PC 브라우저에서 `http://192.168.0.10:8765` 를 열어 `woorizip-radio ok`가 보이면 성공.
6. NAS 방화벽을 켜 두었다면 **제어판 → 보안 → 방화벽**에서 TCP 8765를 내부망에만 허용하세요.
   공유기 포트포워딩은 **하지 마세요** (집 밖에서 접속할 필요 없음).

컨테이너 로그(Container Manager → 컨테이너 → woorizip-radio → 로그)에서 누가 접속했고 누가 말했는지 볼 수 있습니다. 음성은 저장하지 않습니다.

---

## 2. 앱 빌드 (PC 1회)

1. PC에 **Android Studio**를 설치합니다.
2. Android Studio에서 **Open → `android` 폴더**를 엽니다. 처음엔 필요한 구성요소를 내려받느라 몇 분 걸립니다.
3. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
4. 완료 알림의 **locate**를 누르면 `app-debug.apk`가 있는 폴더가 열립니다.
5. 이 APK 파일을 가족 폰으로 보냅니다 (NAS File Station, USB, 메신저 파일 전송 등).

---

## 3. 가족 폰 설치·설정 (폰마다)

1. APK를 열어 설치합니다. "출처를 알 수 없는 앱" 설치 허용을 물으면 허용하세요.
2. 앱을 열면 설정 화면이 나옵니다.
   - NAS 주소: `192.168.0.10` (위에서 고정한 주소)
   - 포트: `8765`
   - 내 이름: `엄마` / `아빠` / `첫째` / `둘째` / `셋째` 중 하나 (서버 MEMBERS와 똑같이)
   - 가족 암호: `FAMILY_KEY`와 똑같이
3. **저장하고 연결** → 마이크·알림 권한 허용
4. **배터리 최적화 제외** 버튼을 누르고 허용합니다.
5. **삼성 폰이라면 추가로**: 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 "우리집 무전기" 추가.
   이걸 안 하면 몇 시간 뒤 수신이 끊길 수 있습니다.
6. 상단에 "우리집 무전기 · 수신 대기 중" 알림이 떠 있으면 준비 완료.

---

## 3-1. 데스크톱·노트북 설치 (Windows)

1. `pc` 폴더를 통째로 PC에 복사하고 **`설치.bat`**을 더블클릭합니다.
   - Python이 없으면 내려받기 페이지가 열립니다. 설치 첫 화면에서 **"Add python.exe to PATH"** 체크 후 설치하고, `설치.bat`을 다시 실행하세요.
   - 설치가 끝나면 바탕화면에 **우리집 무전기** 바로가기가 생기고 프로그램이 실행됩니다.
2. 처음 실행하면 설정 창이 뜹니다.
   - NAS 주소·포트·가족 암호: 폰과 동일
   - 내 이름: **이 PC를 주로 쓰는 가족** (예: 데스크톱은 `아빠`, 노트북은 `엄마`). 폰과 같은 이름이어도 됩니다.
   - 말하기 단축키: 기본 `F9`. 게임 등에서 F9를 쓰고 있으면 `f8`, `scroll lock` 등으로 바꾸세요.
   - **Windows 시작 시 자동 실행**: 기본 켜짐. 부팅 후 최소화 상태로 조용히 켜져서 바로 수신합니다.
3. 창을 닫으면 "완전히 끌까요?"를 묻습니다. **아니요**를 누르면 최소화 상태로 계속 듣습니다.
4. 제거하려면 `제거.bat`을 실행하세요 (자동 실행·프로그램·설정 모두 삭제).

PC에서는 **다른 프로그램을 쓰는 중에도** 단축키를 누르고 있는 동안 말할 수 있고, 가족이 말하면 스피커로 나오면서 작업 표시줄의 무전기 창이 깜빡입니다. 마이크가 없는 PC는 듣기만 됩니다.

## 4. 사용법

| 상황 | 방법 |
|---|---|
| 앱 화면에서 | 상대(전체/가족) 고르고 큰 버튼을 누르는 동안 말하기 |
| 앱 화면이 켜져 있을 때 | 볼륨 버튼 0.5초 이상 누르는 동안 말하기 |
| 화면 꺼짐·잠금 상태 | 볼륨 버튼 길게 누르기 (설정에 따라 두 번 누르기) |
| 잠금 화면 알림 | "말하기 시작" → "말하기 끝" 버튼 |
| 볼륨 짧게 한 번 | 평소처럼 음량 조절 |
| PC (다른 창 사용 중에도) | `F9` 누르고 있는 동안 말하기, 또는 창의 큰 버튼 |

- 말하기가 시작되면 **"삐" + 짧은 진동**, 다른 가족이 말하는 중이라 못 하면 **낮은 음 + 두 번 진동**으로 알려줍니다. 화면을 안 봐도 알 수 있어요.
- 상대는 마지막으로 고른 사람으로 유지됩니다. 화면 꺼짐 송신과 PC 단축키 송신은 그 상대에게 갑니다.
- 한 사람에게 말하면 그 사람의 폰·PC 모두에서 들립니다. 내가 말할 때 내 다른 기기에서는 들리지 않습니다.
- 한 번에 집 전체에서 한 기기만 말할 수 있습니다. 아빠가 PC로 말하는 중이면 아빠 폰에서도 말할 수 없습니다.
- 폰이 **무음·진동 모드**면 소리 대신 진동 + 알림으로만 알려줍니다.
- **방해금지**를 켜면 소리·진동 없이 무시합니다.
- 집 밖에서는 자동으로 연결이 끊기고, 집 Wi-Fi에 다시 붙으면 자동 재연결됩니다.
- 집 인터넷이 끊겨도 공유기와 NAS만 켜져 있으면 동작합니다.

## 5. 알아 둘 제약 (안드로이드 정책)

- **화면 꺼짐 볼륨키 송신은 기종마다 동작이 다를 수 있습니다.** 다른 앱에서 음악·영상이 재생 중이면 볼륨 버튼은 그 앱 음량으로 갑니다. 길게 누르기가 화면 꺼진 상태에서 인식되지 않으면 설정에서 **"두 번 눌러 켜기/끄기"**로 바꿔 보세요. 둘 다 안 되면 잠금 화면 알림의 버튼을 쓰면 됩니다.
- **재부팅 후에는 앱을 한 번 열어야 합니다.** 안드로이드 14부터 마이크를 쓰는 서비스는 부팅 직후 자동으로 켤 수 없습니다. 재부팅되면 "눌러서 수신 대기를 다시 켜 주세요" 알림이 뜹니다.
- 앱을 **강제 종료**하면 수신도 멈춥니다.
- 알림에 "말하기를 쓰려면 앱을 한 번 열어 주세요"가 보이면, 시스템이 서비스를 재시작하면서 마이크 권한이 빠진 상태입니다. 앱을 한 번 열면 해결됩니다.
- 1단계는 음성을 압축하지 않고 보냅니다 (말하는 동안 약 0.25Mbps). 집 Wi-Fi에서는 문제없고, Opus 압축은 다음 단계에서 붙입니다.

## 6. 1단계 테스트 체크리스트

폰 2대로 먼저 확인하고, 이상 없으면 5대로 늘리세요.

- [ ] 두 폰 모두 "● 연결됨" 표시, 서로 접속 표시(●) 보임
- [ ] 전체 방송: A가 말하면 B에서 "삐" 후 소리 나옴
- [ ] 1:1: A가 B를 골라 말하면 B만 들림 (3대일 때 C는 안 들림)
- [ ] 동시에 누르면 늦게 누른 쪽은 거절음
- [ ] B 화면을 끄고 A가 말해도 B에서 들림
- [ ] **A 화면을 끄고 볼륨 버튼 길게 눌러 말하기** → B에서 들림
- [ ] 안 되면 두 번 누르기 모드로 바꿔서 다시 확인
- [ ] 무음 모드에서 진동 + 알림만 오는지
- [ ] Wi-Fi 껐다 켜면 자동 재연결
- [ ] 2~3시간 화면 꺼 둔 뒤에도 수신되는지, 배터리 사용량 확인
- [ ] PC: 게임·브라우저 등 다른 창에서 F9 누르고 말하면 폰에서 들리는지
- [ ] PC: 폰에서 말하면 PC 스피커로 나오고 창이 깜빡이는지
- [ ] 같은 사람 폰+PC 동시 접속 후, 다른 가족이 그 사람에게 1:1로 말하면 둘 다 들리는지
- [ ] PC 재부팅 후 자동으로 켜지는지

문제가 생기면 어떤 기종에서 어떤 항목이 안 되는지 알려 주세요.
