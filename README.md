# 우리집 — 설치·사용 안내 (쉬운 버전)

가족 5명(엄마·아빠·첫째·둘째·셋째)이 **폰 + 데스크톱 + 노트북**으로 함께 쓰는 가족 무전기예요.
우리 집 NAS 주소와 가족 암호는 **설치 파일 안에 이미 들어 있어서**, 설치할 때는 "이 기기는 누구 것인지"만 고르면 돼요.

**이렇게 동작해요**
- **집에서**: 누가 말하면 가족 모두의 폰·PC 스피커에서 바로 들려요. (진짜 무전기처럼)
- **밖에 있는 엄마·아빠**: 폰 데이터로 바로 소리가 울려요. (폰에 Tailscale이 켜져 있어야 해요)
- **밖에 있는 아이들**: 소리 없이 **진동 + 알림**만 와요. 알림의 **[듣기]**를 누르면 그때 들려요. (밖에서 창피하지 않게)
- **데이터가 안 될 때**(지하철 등): NAS가 보관했다가 연결되면 전달해요. 보내는 글도 연결되면 자동으로 나가요.
- **전체**에게도, **고른 1~4명**에게만도 말하고 글을 보낼 수 있어요.
- **말하기 어려울 때는 글로** 보낼 수 있어요. "네", "알겠어요", "지금 갈게요" 같은 빠른 답장 버튼이 있고, 폰은 알림에서 바로 답장돼요. 집에 있는 폰은 받은 글을 소리로 읽어 줘요.
- 보낸 메시지 아래에 **✓ 받음 · ✓✓ 봄(들음)** 이 표시되고, **⏰ 예약**으로 정해진 시간에 보낼 수도 있어요.

---

## 0. 자동 업데이트 (한 번 설치한 뒤에는 할 일 없음)

- NAS 서버가 10분마다 GitHub의 최신 버전을 확인해 설치 파일을 받아 두고, 가족 기기들이 NAS에서 받아가요.
- **PC**: 켜지고 2분 뒤(그리고 12시간마다) 확인 → 새 버전이 있으면 미리 받아 두었다가, 아무도 말하지 않고 창이 트레이에 숨겨져 있을 때 조용히 교체하고 다시 켜져요 ("새 버전 v○○으로 업데이트됐어요" 알림).
- **폰**: 앱이 켜져 서버에 붙을 때(그리고 6시간마다) 확인 → 새 버전이 있으면 받아서 설치를 요청해요. 설정의 **[지금 업데이트 확인]**으로 바로 확인할 수도 있어요. **처음 한 번은** "새 버전 설치" 알림을 눌러 [설치]를 확인해야 하고(안드로이드 규칙), 그 뒤로는 앱이 스스로 교체돼요. 교체된 뒤 수신 대기도 자동으로 다시 켜져요.
- 새 버전이 올라오는 곳: GitHub Releases (빌드 때마다 PC 프로그램 자동 점검을 통과한 것만 올라감).

## 1. 내려받기 (처음 한 번)

GitHub 저장소의 **Releases** 페이지에서 가장 위(최신) 항목을 열면 파일 2개가 있어요. 번호가 클수록 새 거예요.

- `WoorizipRadio-PC-v번호.exe` → PC용
- `WoorizipRadio-Phone-v번호.apk` → 폰용

릴리스 설명의 "PC 프로그램 자동 점검 결과"는 GitHub 컴퓨터에서 실제로 프로그램을 띄워 눌러 본 기록이에요. 전부 OK면 안심하고 받으세요.

## 2. PC 설치 (데스크톱·노트북 각각)

1. `WoorizipRadio-PC-v번호.exe`를 **아무 데서나** 더블클릭하세요.
   - 이 파일은 설치 파일이에요. 프로그램을 PC 안(사용자 폴더 `WoorizipRadio\app`)에 폴더로 풀어 넣고 실행해요. 폴더 형태라 켜는 것도, 이미 켜져 있을 때 창을 다시 여는 것도 빨라요. Windows 시작 시 자동 실행도 그걸로 등록돼요.
   - **다운로드한 파일은 지워도 돼요.** 새 버전도 그냥 실행만 하면 알아서 교체돼요.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**. (가족용 프로그램이라 서명이 없어서 그래요)
2. 처음 한 번 **"이 PC는 누구 것인가요?"** 가 떠요. 이름을 고르고 **시작**.
3. 끝! 오른쪽 아래 시계 옆에 **별 아이콘**이 생기고, 창의 상태 줄이 초록색 "● 아빠 · 연결됨 · 가족 3명" 처럼 바뀌면 연결된 거예요.
   - 바탕화면 바로가기가 필요하면 **설정 → 바탕화면에 바로가기 만들기** (여러 번 눌러도 하나만 생겨요). 시작 메뉴에는 '우리집'이 자동으로 들어가요. 작업 표시줄에 두려면 실행 중인 별 아이콘을 우클릭 → 작업 표시줄에 고정.
   - 예전에 고정해 둔 작업 표시줄 아이콘이 빈 문서 모양이면(지운 다운로드 파일을 가리키는 것) 프로그램이 켜질 때 스스로 고쳐요. 그래도 그대로면 한 번 고정 해제 후 다시 고정하세요.
   - 창을 닫아도 아이콘으로 남아 계속 듣고 있어요. 다시 열려면 아이콘 클릭 또는 바로가기 실행 (이미 켜져 있으면 그 창이 앞으로 나와요).
   - 가족이 말하거나 글을 보내면 **오른쪽 아래에 작은 팝업**이 5초쯤 떠요. 팝업을 **클릭하면 바로 답장**할 수 있어요.
   - 완전히 끄려면 아이콘 우클릭 → **완전히 종료** → 가족 암호 입력 (아이들이 함부로 끄지 못하게)
4. 사용자나 주소를 바꿔야 할 때만: **설정 → 사용자·주소 변경 (가족 암호 필요)**. 아이들이 실수로 못 바꾸게 암호를 물어요.
5. 제거하려면 설정에서 자동 실행을 끄고 완전히 종료한 뒤, `C:\Users\(사용자)\AppData\Local\WoorizipRadio` 폴더를 지우면 돼요.

## 3. 폰 설치 (가족 폰 각각)

**(밖에서도 쓰려면) Tailscale 먼저**
1. 플레이스토어에서 **Tailscale**을 설치하고, NAS에서 쓴 것과 **같은 계정**으로 로그인하세요.
2. 연결(Connected)로 켜 두세요. 설정에서 **항상 켜진 VPN**으로 해 두면 꺼지지 않아요.
   (집에서만 쓸 거면 건너뛰어도 돼요.)

**우리집 앱**
1. `WoorizipRadio-Phone-v번호.apk`를 폰으로 보내서(카톡 나에게 보내기, NAS 등) 눌러 설치하세요.
   "출처를 알 수 없는 앱" 허용을 물으면 허용하세요. 새 버전은 기존 앱 위에 그냥 덮어 설치돼요.
2. 앱을 열면 처음 한 번 **"이 폰은 누구 것인가요?"** 가 떠요. 이름을 고르고 **시작**.
3. 마이크·알림 권한 **허용**, **배터리 최적화 제외** 허용.
4. **삼성 폰은 한 가지 더**: 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 "우리집" 추가.
   안 하면 몇 시간 뒤 수신이 끊길 수 있어요.
5. 앱 ⚙ 설정의 **수신 대기** 스위치가 켜져 있으면 준비 끝! (알림창을 내리면 맨 아래에 "우리집 · 수신 대기 중"이 작게 보여요. 상단 아이콘은 안 뜨게 해 두었고, 기종에 따라 남으면 설정의 **[상단 '수신 대기' 알림 숨기기…]**로 끌 수 있어요 — 수신·메시지 알림은 그대로예요.)

폰을 껐다 켜도 듣기는 자동으로 켜져요. (말하기는 안드로이드 규칙상 앱을 한 번 열어야 다시 돼요.)

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 모두에게 말하기 | **모두** 방 선택 → 큰 버튼 누른 채 말하기 → 손 떼면 끝 |
| 한 사람에게 | 그 사람 방(👩 엄마, 👨 아빠, 🧒 첫째…)을 누르기 → 큰 버튼이 "엄마에게 말하기"로 바뀜 |
| 아이들에게 | **아이들** 방 (묶음은 설정에서 바꿀 수 있어요) |
| 나에게 메모 | 방 버튼 중 **내 자리("📝 나")** 를 누르고 글·사진을 보내면 **내 기기들에서만** 보이는 메모가 돼요 (다른 가족에게는 전달·알림 없음, 음성은 안 됨) |
| 몇 명만 골라서 | PC는 사람 방 **우클릭**, 폰은 **길게 누르기**로 추가·제외 |
| 폰 화면 꺼진 채로 말하기 | **볼륨 버튼 길게** 누른 채 말하기 (마지막에 고른 상대에게) |
| 잠금 화면에서 | 알림의 **[말하기 시작] / [말하기 끝]** 버튼 |
| 밖에서 받은 말 듣기 (아이) | 알림의 **[듣기]**, 또는 앱의 메시지 목록에서 |
| PC에서 말하기 | 창의 큰 버튼 (설정에서 단축키를 정하면 다른 창에서도) |
| 말할 수 없을 때 (회의·수업 중) | **글로 보내기**: 빠른 답장 버튼 또는 직접 입력 → 보내기 |
| 폰 알림에서 바로 답장 | 알림의 **[답장]** → 글 선택 또는 입력 |
| PC 팝업에서 바로 답장 | 오른쪽 아래 팝업 클릭 → 빠른 답장 또는 입력 |
| 보낸 글을 봤는지 확인 | 보낸 메시지 아래 **엄마✓✓ 첫째✓ 둘째·** 처럼 표시 (· 보냄, ✓ 받음, ✓✓ 봄·들음) |
| 정해진 시간에 보내기 | **⏰ 예약** → 내용·시간·반복(한 번/매일/평일/주말) → 예약 추가. NAS가 시간이 되면 대신 보내요 (내 기기가 꺼져 있어도) |
| 빠른 답장 문구 바꾸기 | 설정에서 쉼표로 구분해 적기 |
| 사진·파일 보내기 | 폰: 입력줄 **📎** → 사진·동영상 / 파일 / 카메라, 또는 갤러리에서 **공유 → 우리집**. PC: **📎** 버튼, 또는 스크린샷·파일을 **Ctrl+V**로 붙여넣기 |
| 받은 사진·파일 | 사진은 말풍선에 미리보기로 바로 보이고 누르면 크게. 파일은 📎 이름·크기, 누르면 열기. 길게 누르기(PC는 우클릭)로 갤러리에 저장·공유·다른 이름으로 저장 |

- 말하기가 시작되면 **"삐" + 짧은 진동**, 다른 사람이 말하는 중이면 **낮은 음 + 두 번 진동**이에요.
- 방 버튼은 폰에서 **[모두][아이들] / [아빠][엄마] / [첫째][둘째][셋째]** 세 줄로 고정이고, 내 자리에는 "나"가 보여요. 버튼·말풍선·알림에 보이는 **이름은 NAS의 `names.json`에서 정해요** (아래 "보이는 이름" 참고) — 앱 안에는 실제 이름이 들어 있지 않아요.
- 방 버튼에 연결된 사람은 **초록 점**, 안 된 사람은 **꺼짐**, 그리고 **새 글 개수**가 보여요. (집/밖 구분은 밖에 있는 아이에게 진동으로 주는 동작에만 쓰고 글자로는 안 보여요.) 사람마다 색이 정해져 있고(엄마 분홍, 아빠 파랑, 첫째 초록, 둘째 주황, 셋째 보라) 받은 메시지의 이름에도 같은 색이 붙어요.
- 대화는 카톡처럼 **말풍선**으로, 최신이 아래에 와요 (내 글은 오른쪽). 위로 올려 옛 글을 보는 중이면 새 글이 와도 끌어내리지 않고 "새 메시지 ↓" 버튼만 떠요. 고른 방의 대화만 보여 주고, **모두** 방에서는 전부 보여요. **같은 사람과 주고받은 연속 글은 그 사람 색 테두리 상자**("🧒 첫째와의 대화")로 묶여서, 모두에게 보낸 글(상자 없음)과 1:1 글이 한눈에 갈려요.
- 문자 대화는 NAS가 **전부, 기간 제한 없이** 보관해서 폰·PC 어디서 열어도, 새 기기를 설치해도 같은 대화가 보여요(처음엔 최근 120개, 대화창을 **맨 위까지 올리면 더 옛 글**을 이어 받아요). 보관 파일은 **암호화**돼 있고 열쇠는 NAS의 `docker/woorizip-radio/history.key`에만 있어요 — NAS 백업에 이 파일을 꼭 넣으세요(잃으면 옛 기록을 못 읽어요). 음성은 기기에 24시간 보관. **내가 폰에서 보낸 글·사진은 내 PC에도 바로 뜨고, 한 기기에서 읽으면 다른 기기의 "새 글" 표시도 같이 사라져요.**
- 첨부파일은 NAS(`docker/woorizip-radio/files/`)에 저장되고 **7일 뒤 자동 삭제**돼요(말풍선엔 "기간이 지나 삭제됐어요"로 남음). 크기 제한은 사실상 없지만 안전장치로 파일 하나 4GB, 전체 50GB(넘으면 오래된 것부터 삭제), NAS 여유 공간 2GB는 남겨요. 사진은 보내는 쪽에서 작은 미리보기를 같이 올려서 받는 쪽은 미리보기만 먼저 받고 원본은 누를 때 받아요(데이터 절약).
- 말풍선을 PC는 우클릭, 폰은 길게 누르면 복사·삭제·그 사람 방으로.
- 한 번에 한 사람만 말할 수 있고, 한 번에 최대 1분이에요.
- **말소리가 실제로 들어와야** 가족에게 "말하는 중" 신호와 소리가 나가요. 버튼을 스치거나 말 없이 눌렀다 떼면 아무 일도 안 생기고, 내 화면에 "소리가 안 들려 보내지 않았어요"만 떠요. 폰은 실제로 나가기 시작할 때 짧게 한 번 진동해요.

## 보이는 이름 (names.json) — NAS에만

앱·PC 프로그램은 가족을 `엄마 아빠 첫째 둘째 셋째`라는 **자리 이름**으로만 알아요. 화면에 다른 이름으로 보이게 하려면 NAS의 `docker/woorizip-radio/names.json`에 적어 두면 서버가 접속할 때 알려 줘요 (파일이 없으면 자리 이름 그대로).

```json
{"첫째": "홍길동", "둘째": "...", "셋째": "...",
 "by_viewer": {"아빠": {"엄마": "엄마에게만 보일 이름"}, "엄마": {"아빠": "..."}}}
```

- 위쪽은 모든 기기에 공통, `by_viewer`는 **보는 사람별**이에요 (예: 아빠 기기에서만 엄마가 다른 이름으로).
- 이 파일은 이 저장소(GitHub)에 올리지 마세요 — 실제 이름은 NAS 안에만 두는 게 원칙이에요. 바꾼 뒤에는 앱을 다시 접속하면 반영돼요.

## PC 프로그램 Rust판 (써 보는 중 → 곧 기본)

저장소의 `pc-rust/`에 PC 프로그램을 **Rust로 새로 만든 판**이 있어요. 릴리스에 `WoorizipRadio-PCRust-v번호.exe`로 따로 올라와요.

- **설치**: 그 파일을 더블클릭하면 돼요. 켜져 있는 Python판을 스스로 끄고 같은 자리(`사용자 폴더\WoorizipRadio\app`)에 들어가며, 설정(`config.json`)과 대화 기록은 그대로 이어져요. 파일 하나라 설치가 빠르고 메모리도 적게 써요.
- **달라진 점**: 방 버튼 3줄 격자(내 자리 "나"), 말하기 버튼 1/3 높이, 받은 표시가 기호 대신 **"○○ 읽음 · ○○ 받음"** 글자, 사진 크게 보기(Ctrl+휠 확대), 파일을 창에 **끌어다 놓기**, Ctrl+V 스크린샷, 🔍 대화 검색, 마이크 잡음 줄이기, 가족 암호를 Windows 계정 열쇠(DPAPI)로 잠가 저장.
- **보안**: 자동 업데이트는 NAS에서 받은 파일의 sha256과 **ed25519 서명**이 맞을 때만 설치해요. 서명은 GitHub의 비밀 `PC_SIGN_KEY`로 빌드 때 붙고, 프로그램 안에는 공개 열쇠만 있어요(`pc-rust/src/update.rs`). 비밀이 등록되지 않은 빌드는 "서명 없음"으로 설치를 거부해요.
- **점검**: 빌드마다 GitHub 컴퓨터에서 서버를 켜고 `--selftest`(21항목: 글·읽음·메모·음성·예약·첨부·서명)와 실제 설치·교체 흐름을 돌려요. 릴리스 설명에 결과가 붙어요.
- 문제가 생기면 `C:\Users\(사용자)\AppData\Roaming\WoorizipRadio\log_rust.txt`를 보내 주세요.

## 알아 두면 좋은 것

- **화면 꺼진 상태 볼륨키 말하기는 기종마다 달라요.** 안 되면 앱 설정에서 "두 번 눌러 켜기/끄기"로 바꿔 보고, 그래도 안 되면 잠금 화면 알림 버튼을 쓰세요.
- 밖에서는 Tailscale이 켜져 있어야 연결돼요. 아이 폰에서 Tailscale을 꺼 버리면 집에서만 돼요.
- 배터리는 메신저 앱 하나 더 켜 둔 정도예요 (밖에서는 2분에 한 번만 신호). 위치 추적은 전혀 안 해요.
- PC 프로그램은 트레이에 조용히 있을 때 메모리를 거의 쓰지 않도록 만들었어요 (받은 음성은 파일로만 보관).
- 음성은 NAS 메모리에만 잠깐(최대 24시간) 보관되고 파일로 저장되지 않아요. 폰·PC에는 최근 30~40개만 남아요.
- 문제가 생기면 PC는 `C:\Users\(사용자)\AppData\Roaming\WoorizipRadio\log.txt` 기록 파일을 보내 주세요.

## NAS 서버 (참고 — 이미 설치되어 있음)

- NAS의 Docker 앱에 `woorizip-server` 컨테이너가 돌고 있어요. 파일은 File Station의 `docker/woorizip-radio/server.py` 예요.
- 서버를 새 버전으로 바꿀 때: 새 `server.py`를 같은 폴더에 올리고(예전 것은 `server_old_v번호.py`로 이름 바꿔 보관) Docker 앱에서 컨테이너를 **다시 시작**하면 돼요. 로그에 "우리집 무전기 서버 시작"이 보이면 성공.
- 첨부파일 보관 기간·상한은 환경 변수 `FILE_KEEP_DAYS`(7), `MAX_FILE_GB`(4), `FILES_TOTAL_GB`(50)로 바꿀 수 있어요. 첨부 업로드·다운로드도 가족 암호가 있어야 하고, 파일 이름은 표시용일 뿐 저장은 난수 id로 해서 경로 장난이 통하지 않아요.
- 음성 감지 기준은 컨테이너 환경 변수 `VOICE_GATE`(기본 400)로 바꿀 수 있어요. TV 소리에 잘못 나가면 올리고, 조용히 말할 때 안 나가면 내리세요. 로그의 "최대 음량" 숫자가 기준이에요. 0이면 끔.
- 예약 메시지는 같은 폴더의 `schedules.json`에 저장돼요 (NAS를 재시작해도 남아요).
- 자동 업데이트용 설치 파일은 같은 폴더의 `updates/`에 쌓여요 (최신 것만 남김). 저장소가 비공개가 되면 `github_token.txt`에 읽기 전용 토큰을 넣어야 받아올 수 있어요.
- 공유기 포트포워딩은 필요 없어요. NAS 방화벽을 쓰고 있다면 TCP 8765를 허용하세요.

## 처음 해 볼 테스트 (폰 1대 + PC 1대)

- [ ] 둘 다 초록 "● 연결됨" 표시
- [ ] PC에서 말하면 폰에서 들림 / 폰에서 말하면 PC에서 들림
- [ ] 폰 화면 끄고 PC에서 말해도 폰에서 들림
- [ ] 폰 화면 끈 채 볼륨 버튼 길게 눌러 말하면 PC에서 들림
- [ ] 폰에서 글을 보내면 PC 오른쪽 아래 팝업이 뜨고, 클릭해 답장하면 폰 알림으로 옴
- [ ] 보낸 글 아래 ✓ → ✓✓ 로 바뀜
- [ ] 폰 Wi-Fi를 끄고(데이터만) PC에서 말하면 부모는 소리, 아이는 진동+알림
- [ ] 폰 앱을 껐다가 다시 켜면 그동안 온 말이 메시지 목록에 있는지

안 되는 항목이 있으면 **어느 기기에서 어떤 항목**이 안 되는지 알려 주세요.
